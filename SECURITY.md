# Security Policy

## Supported code

TrainerForge is under active development. Security fixes target the current
default branch (`main`). Historical development snapshots do not have a separate
security maintenance commitment. Review a reported issue against the relevant
development branch when it has not yet reached `main`.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/NaXeMate/Trainer-Forge/security/advisories/new)
once it is enabled. The activation steps are documented in
[GitHub security setup](Documentation/GITHUB_SECURITY.md).

Include the affected branch or commit, steps to reproduce the issue, its impact,
and a proof of concept using synthetic data. Do not include real credentials,
tokens, or personal data. Do not open a public issue containing exploit details.

If the private reporting form is unavailable, use a public issue only to request
a private reporting channel, without disclosing the vulnerability.

## Política de seguridad

TrainerForge está en desarrollo. Las correcciones de seguridad se dirigen a la
rama predeterminada actual (`main`); las versiones históricas de desarrollo no
tienen un mantenimiento de seguridad independiente. Si el problema pertenece a
una funcionalidad todavía no integrada, indica la rama de desarrollo afectada.

Comunica los fallos mediante el
[formulario privado de GitHub](https://github.com/NaXeMate/Trainer-Forge/security/advisories/new)
cuando esté activado. Incluye la rama o commit, los pasos para reproducirlo, el
impacto y una prueba con datos ficticios. No compartas credenciales, tokens ni
datos personales reales, ni publiques detalles de explotación en un issue.

Si el formulario no está disponible, abre un issue únicamente para solicitar
un canal privado, sin describir la vulnerabilidad.
